# Persian AI Resume Analyzer

سامانه‌ای برای استخراج، پردازش و تحلیل رزومه‌های فارسی با استفاده از روش‌های Rule-Based و مدل‌های زبانی بزرگ (LLM).

این پروژه با Python و Streamlit توسعه داده شده است و قابلیت‌هایی مانند استخراج متن از رزومه PDF، پاک‌سازی متن فارسی، استخراج ساختاریافته اطلاعات رزومه، ارزیابی اولیه، امتیازدهی، تحلیل هوشمند رزومه، ارزیابی کیفیت و بررسی ATS را فراهم می‌کند.

---

## Requirements

برای اجرای پروژه موارد زیر مورد نیاز است:

- Python 3.10
- pip
- اتصال اینترنت برای استفاده از API مدل‌های زبانی
- API Key معتبر برای سرویس‌های مورد استفاده

نسخه پیشنهادی Python:

```text
Python 3.10.x
```

---

## 1. Download the Project

ابتدا پروژه را دانلود کرده و فایل‌ها را از حالت فشرده خارج کنید.

سپس Terminal یا Command Prompt را در پوشه اصلی پروژه باز کنید.

پوشه اصلی باید شامل فایل‌هایی مانند موارد زیر باشد:

```text
app.py
requirements.txt
style.py
```

---

## 2. Create Virtual Environment

برای جلوگیری از تداخل کتابخانه‌های پروژه با سایر محیط‌های Python، ابتدا یک Virtual Environment ایجاد کنید.

در Terminal و در مسیر اصلی پروژه دستور زیر را اجرا کنید:

```bash
python -m venv venv
```

---

## 3. Activate Virtual Environment

در Windows محیط مجازی را با دستور زیر فعال کنید:

```bash
venv\Scripts\activate
```

پس از فعال شدن موفق محیط مجازی، معمولاً عبارت زیر در ابتدای خط Terminal نمایش داده می‌شود:

```text
(venv)
```

---

## 4. Install Required Libraries

کتابخانه‌های مورد نیاز پروژه در فایل `requirements.txt` قرار گرفته‌اند.

برای نصب تمام وابستگی‌های پروژه دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

تا پایان نصب کتابخانه‌ها منتظر بمانید.

---

## 5. Configure API Keys

پروژه برای تحلیل مبتنی بر مدل زبانی از API استفاده می‌کند.

در پوشه اصلی پروژه یک فایل با نام زیر ایجاد کنید:

```text
.env
```

سپس API Keyهای مورد نیاز را در آن قرار دهید.

نمونه:

```env
GEMINI_API_KEY=your_gemini_api_key
OPENROUTER_API_KEY=your_openrouter_api_key
```

عبارت‌های `your_gemini_api_key` و `your_openrouter_api_key` باید با API Keyهای معتبر جایگزین شوند.

> نکته امنیتی: فایل `.env` حاوی اطلاعات محرمانه است و نباید در مخزن عمومی GitHub قرار داده شود.

---

## 6. Run the Application

بعد از فعال‌سازی Virtual Environment، نصب کتابخانه‌ها و تنظیم API Keyها، برنامه را با دستور زیر اجرا کنید:

```bash
streamlit run app.py
```

پس از اجرای دستور، Streamlit برنامه را اجرا می‌کند و رابط کاربری پروژه در مرورگر باز خواهد شد.

آدرس Local برنامه معمولاً به صورت زیر است:

```text
http://localhost:8501
```

# Main Features

قابلیت‌های اصلی پروژه شامل موارد زیر است:

- آپلود رزومه فارسی در قالب PDF
- استخراج متن PDF
- پاک‌سازی و آماده‌سازی متن فارسی
- استخراج ساختاریافته اطلاعات رزومه
- ارزیابی اولیه رزومه به روش Rule-Based
- امتیازدهی رزومه
- نمایش جزئیات و نحوه محاسبه امتیاز
- تحلیل رزومه با استفاده از مدل زبانی
- ارزیابی کیفیت رزومه
- بررسی سازگاری با ATS
- ارائه نقاط قوت و ضعف
- ارائه پیشنهادهای بهبود رزومه
- اتصال به Gemini
- استفاده از OpenRouter به‌عنوان سرویس جایگزین در شرایط مشخص

# Project Structure

ساختار کلی پروژه به شکل زیر است:

```text
Resume Analyzer AI/
│
├── app.py
├── style.py
├── requirements.txt
│
├── assets/
│   └── fonts/
│
├── prompts/
│
├── services/
│
├── utils/
│
└── views/
```

### `app.py`

فایل اصلی اجرای برنامه و مدیریت جریان کلی رابط کاربری Streamlit است.

### `style.py`

تنظیمات مربوط به ظاهر رابط کاربری، نمایش فارسی، راست‌چین‌سازی و فونت‌های پروژه در این بخش مدیریت می‌شوند.

### `services/`

شامل منطق اصلی پردازش و تحلیل رزومه، استخراج ساختاریافته، ارزیابی Rule-Based و ارتباط با سرویس‌های مدل زبانی است.

### `prompts/`

شامل Promptهای مورد استفاده برای استخراج، تحلیل و ارزیابی رزومه توسط مدل‌های زبانی است.

### `views/`

مسئول نمایش بخش‌های مختلف نتایج در رابط کاربری Streamlit است.

### `utils/`

شامل ابزارهای کمکی مانند خواندن فایل PDF و پاک‌سازی متن استخراج‌شده است.

### `assets/fonts/`

شامل فونت‌های فارسی مورد استفاده در رابط کاربری پروژه است.

```bash
python -m venv venv
```

سپس:

```bash
venv\Scripts\activate
```

سپس:

```bash
pip install -r requirements.txt
```

پس از تنظیم API Keyها در فایل `.env`، برنامه را اجرا کنید:

```bash
streamlit run app.py
```

پس از اجرای آخرین دستور، برنامه در مرورگر باز شده و آماده دریافت و تحلیل رزومه خواهد بود.
